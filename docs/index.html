Key Features

  • Interactive Radar System

    Discover active BLE exhibition beacons in real-time as you navigate Himalaya College of Engineering.

  • Showcase & Projects Browser

    Explore structural art models, automated civil siphon spillways, and dynamic student project galleries.

  • Spatial Walking Navigation

    Easily find exhibition landmarks like Block B, Registration Desks, and Robo Soccer Arenas.

  • Fully Offline Capable

    Preloaded dynamic SQLite catalog with seamless on-launch database updates. No continuous internet needed.
